# Консольное приложение для формирования заявки на строительные материалы с логикой "удержания клиента"

## Задача
Разработать консольное приложение, которое позволяет сформировать заявку на строительные материалы с учетом региона, групп товаров и логики “удержания клиента” (предложение более дешевого аналога или скидки)

### Приложение должно:
- Работать с локальным каталогом материалов
- корректно обрабатывать ввод пользователя
- создать JSON-файл заявки при подтверждении заказа

### Логика приложения
Пользователь выбирает регион, затем выводится список товаров и их цена для выбранного региона.
После выбора товара пользователь может подтвердить заказ или отказаться от него. Если пользователь отказывается, приложение должно предложить более дешевый аналог или скидку на выбранный товар.

### Логика "Удержани клиента"
Если пользователь отказывается от выбранного товара, приложение должно:
- Определить категорию товара
- Найти более дешевый аналог в той же категории или предложить скидку на выбранный товар в размере 5%
